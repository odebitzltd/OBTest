# Security Policy

## Supported Versions

We issue security updates for supported versions of **OBTest**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **OBTest**, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email or submit a private report with detailed steps to reproduce the issue.

### What to Include in Your Report:
* Description of the vulnerability and its potential impact.
* Steps to reproduce the issue or proof-of-concept code.
* Any potential mitigations or suggested fixes.

We will acknowledge receipt of your report within 48 hours and work with you to resolve and publish a fix in a timely manner.
